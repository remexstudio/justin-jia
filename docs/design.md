# Design

## Direction

Paper and ink. Person, not company. Quiet hierarchy, generous margins, type that reads as a letter more than a landing page.

## Palette (stub)

- **Paper**: warm off-white ground (`#f7f4ef`)
- **Ink**: near-black text (`#1a1917`)
- **Ink muted**: secondary copy (`#5c5954`)
- **Rule**: soft hairline (`#e4e0d8`)

Expand tokens in P1. No purple. No neon. No dark-mode SaaS gradient kits.

## Type

System UI stack for P0. Custom faces only if they beat system defaults for this brief (decide in P1). Avoid Inter as the default “AI template” tell.

## Layout

Single column, max measure ~`max-w-2xl`. Left-aligned body. Home may center the initializing placeholder until the P1 hero lands.

## Motion

None in P0. P6 adds restrained, interruptible motion and `prefers-reduced-motion` respect. No decorative entrance cascades.

## Forbids

- Purple / neon / glassmorphism for its own sake
- Card grids with identical soft shadows
- Tracked ALL-CAPS eyebrows as chrome
- Chinese on ship UI
