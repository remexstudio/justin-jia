# Justin Jia

Personal site for Justin Jia: AI Product Manager in Bellevue, Washington. Founder, Remex Studio.

Recruiter-facing depth to LinkedIn. Not a second company site.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- pnpm

## Develop

```bash
pnpm install
pnpm dev
```

## Build

```bash
pnpm build
pnpm start
```

## Routes

`/` `/now` `/path` `/work` `/writing` `/contact`
