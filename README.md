# Justin Jia

Personal site for Justin Jia: AI Product Manager in Bellevue, Washington. Founder, Remex Studio.

Recruiter-facing depth to LinkedIn. Not a second company site.

## Voice

English letter tone. Person, not company. Paper and ink. Calm and specific over hype. Ship UI is English only.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- pnpm

## Develop

```bash
pnpm install
pnpm dev
```

## Build

```bash
pnpm build
pnpm start
```
